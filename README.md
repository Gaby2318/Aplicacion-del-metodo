# Regresión Logística para Predicción de Admisión Universitaria

## Descripción
Este proyecto implementa **Regresión Logística desde cero** (sin librerías de ML) para predecir si un estudiante será admitido en una maestría basado en su promedio de pregrado y puntaje de examen.
